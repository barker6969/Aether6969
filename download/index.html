Desktop App · v0.1.0 Latest

Native desktop application (Tauri). Includes the full dashboard in its own window and works offline with the local CLI bridge.

Windows MSI ~2.3 MB · x64 macOS DMG ~7 MB · Universal Linux AppImage ~76 MB · x64
Unsigned builds may trigger SmartScreen / Gatekeeper. Prefer the official GitHub Release assets.

aether-cli USB Bridge

Standalone Rust binary that talks to USB devices (MTK / Qualcomm / Apple DFU / Samsung) and exposes a local WebSocket bridge for the dashboard.
Windows x64 · .zip macOS (Intel) x64 · .tar.gz macOS (Apple Silicon) arm64 · .tar.gz Linux x64 · .tar.gz
Note: Pre-built CLI binaries are published when a v* tag is created (see .github/workflows/aether-cli-release.yml). Until then you can build from source:

cd aether-cli && cargo build --release
After download: extract → run aether-cli serve (or aether-cli.exe serve on Windows). The dashboard connects to ws://127.0.0.1:8765.
